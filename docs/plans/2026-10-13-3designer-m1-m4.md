# 3Designer M1~M4 구현 계획

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** JSON 피처 트리 파일을 브라우저에서 3D로 렌더링하고 STL로 내보내며, Claude Code가 파일을 편집하면 즉시 반영되고, UI에서 치수와 피처를 직접 편집해 파일에 되쓰는 CAD 뷰어/편집기를 만든다.

**Architecture:** 모델은 `*.3d.json` 피처 트리 하나가 진실의 원천이다. 브라우저는 Zod로 검증하고 수식을 숫자로 풀어 Web Worker 안의 replicad(OpenCascade WASM)로 B-rep 솔리드를 만들고 메시를 Three.js로 그린다. 로컬 Node 서버가 파일을 감시해 WebSocket으로 브라우저에 밀어주고, UI 편집은 같은 WebSocket으로 파일에 되쓴다. Claude Code는 파일만 편집한다(M5 MCP 이전).

## 사전 검증된 사실 (2026-10-13, 직접 실행해 확인)

계획 작성 전에 replicad 1.1.0을 Node에서 실행해 확인한 내용이다. 구현 시 그대로 믿고 써도 된다.

- Node 초기화: `import opencascade from "replicad-opencascadejs"` → `const OC = await opencascade({ locateFile: () => wasmPath })` → `setOC(OC)`. wasm 경로는 `createRequire(import.meta.url).resolve("replicad-opencascadejs/wasm")`.
- Vite 워커: `import wasmUrl from "replicad-opencascadejs/wasm?url"` 로 wasm URL을 얻고 `locateFile: () => wasmUrl`. `vite.config.ts`에 `optimizeDeps.exclude: ["replicad-opencascadejs"]`, `worker.format: "es"` 필요. 빌드 성공 확인(wasm 23MB).
- `makeBaseBox(x, y, z)`: XY 중심, Z는 0..z. 바운드 `[[-x/2,-y/2,0],[x/2,y/2,z]]`.
- `makeCylinder(r, h, [x,y,z]?)`: 원점에서 +Z로. `makeSphere(r)`: 원점 중심.
- `shape.translate([x,y,z])`, `shape.rotate(deg, [cx,cy,cz], [ax,ay,az])`, `shape.fuse(o)`, `shape.cut(o)`, `shape.intersect(o)` — 모두 새 shape 반환.
- `shape.fillet(r, (e) => e.inPlane("XY", z))`, `shape.chamfer(d, finder)`. 필터 없으면 모든 모서리.
- `EdgeFinder` 메서드: `inPlane(plane, offset)`, `inDirection("Z")`, `ofLength(n)`, `parallelTo(plane)`.
- `drawRectangle(w, h)`, `drawRoundedRectangle(w, h, r)`, `drawCircle(r)`, `drawPolysides(r, n)` → `Drawing`. `drawing.cut(other)`, `.fuse(other)`, `.translate(x, y)`. `drawing.sketchOnPlane("XY", offset).extrude(h)` → Shape3D.
- `measureVolume(shape)`, `shape.boundingBox.bounds` → `[[minX,minY,minZ],[maxX,maxY,maxZ]]`.
- `shape.mesh({ tolerance, angularTolerance })` → `{ vertices: number[], triangles: number[], normals: number[], faceGroups }`. `shape.meshEdges(opts)` → `{ lines: number[], edgeGroups }`.
- `shape.blobSTL({ tolerance, angularTolerance, binary: true })` → Blob.
- **커널 실패는 JS `Error`가 아니라 `WebAssembly.Exception`을 던진다.** `catch (e)`에서 `e instanceof Error`를 가정하지 말고 `String(e)`로 메시지를 만든다. 예: 반경이 너무 큰 필렛.
- 검증된 부피: `makeCylinder(20,20)` = 25132.74, `makeBaseBox(40,20,10)` = 8000, 40×40×5 판에 Ø3.4 구멍 4개 = 7818.42.

## 스키마 결정 (설계 문서에서 구체화)

설계 문서의 6종 피처를 구현 가능한 형태로 확정한다. **SolidWorks처럼 "현재 바디 하나"를 피처가 순서대로 수정**한다.

- 바디를 만드는 피처(`box`, `cylinder`, `sphere`, `extrude`)는 `op` 필드를 가진다: `"add"`(기본, 현재 바디에 합침. 첫 피처면 새 바디), `"cut"`(현재 바디에서 뺌), `"intersect"`. 설계 문서의 `boolean` 피처는 이 `op`로 흡수한다(별도 피처 불필요).
- `hole`: 현재 바디 윗면에서 아래로 뚫는다. `positions`는 `[x,y]` 목록 또는 원형/선형 패턴.
- `fillet`/`chamfer`: 현재 바디의 모서리를 선택자(`top`/`bottom`/`vertical`/`all`)로 고른다. `top`은 바운딩 박스 최상단 Z 평면의 모서리.
- `pattern`: 바디 피처와 `hole`의 선택 필드. 별도 피처가 아니다.
- 모든 숫자 필드는 `number | string(수식)`. 수식은 `parameters`의 변수와 `+ - * / ( )`, 단항 마이너스, `sqrt/sin/cos/abs/min/max`를 지원한다.
- 모든 피처는 `id`, `type`, 선택적 `name`, `suppressed`, `transform: { position?, rotation? }`를 가진다. rotation은 도(deg) 단위, 원점 기준 X→Y→Z 순서.

```ts
// src/model/schema.ts
import { z } from "zod";

/** 숫자 또는 수식 문자열 ("D/2", "H - 2") */
export const Num = z.union([z.number(), z.string().min(1)]);
export type Num = z.infer<typeof Num>;

export const Vec3 = z.tuple([Num, Num, Num]);
export const Vec2 = z.tuple([Num, Num]);

export const Transform = z.object({
  position: Vec3.optional(),
  /** 도(deg) 단위, 원점 기준 X→Y→Z 순서 */
  rotation: Vec3.optional(),
});

export const PatternSpec = z.discriminatedUnion("pattern", [
  z.object({
    pattern: z.literal("linear"),
    count: Num,
    spacing: Num,
    direction: z.enum(["X", "Y", "Z"]).default("X"),
  }),
  z.object({
    pattern: z.literal("circular"),
    count: Num,
    /** 피치 원 지름 */
    diameter: Num,
    startAngle: Num.default(0),
  }),
]);

const BodyOp = z.enum(["add", "cut", "intersect"]).default("add");
const EdgeSelector = z.enum(["top", "bottom", "vertical", "all"]);
const PlaneName = z.enum(["XY", "XZ", "YZ"]).default("XY");

const Base = z.object({
  id: z.string().min(1),
  name: z.string().optional(),
  suppressed: z.boolean().default(false),
  transform: Transform.optional(),
});

const BodyBase = Base.extend({
  op: BodyOp,
  pattern: PatternSpec.optional(),
});

export const Profile = z.discriminatedUnion("kind", [
  z.object({ kind: z.literal("rect"), width: Num, height: Num, cornerRadius: Num.optional() }),
  z.object({ kind: z.literal("circle"), radius: Num }),
  z.object({ kind: z.literal("polygon"), sides: Num, radius: Num }),
]);

export const FeatureSchema = z.discriminatedUnion("type", [
  BodyBase.extend({ type: z.literal("box"), size: Vec3 }),
  BodyBase.extend({ type: z.literal("cylinder"), radius: Num, height: Num }),
  BodyBase.extend({ type: z.literal("sphere"), radius: Num }),
  BodyBase.extend({
    type: z.literal("extrude"),
    profile: Profile,
    plane: PlaneName,
    offset: Num.default(0),
    height: Num,
  }),
  Base.extend({
    type: z.literal("hole"),
    diameter: Num,
    depth: z.union([z.literal("through"), Num]).default("through"),
    positions: z.union([z.array(Vec2).min(1), PatternSpec]),
  }),
  Base.extend({ type: z.literal("fillet"), radius: Num, edges: EdgeSelector.default("all") }),
  Base.extend({ type: z.literal("chamfer"), distance: Num, edges: EdgeSelector.default("all") }),
]);

export const PartSchema = z
  .object({
    version: z.literal(1),
    units: z.literal("mm"),
    parameters: z.record(z.string(), z.number()).default({}),
    features: z.array(FeatureSchema),
  })
  .superRefine((part, ctx) => {
    const seen = new Set<string>();
    part.features.forEach((f, i) => {
      if (seen.has(f.id)) {
        ctx.addIssue({
          code: "custom",
          path: ["features", i, "id"],
          message: `피처 id 중복: "${f.id}"`,
        });
      }
      seen.add(f.id);
    });
  });

export type Part = z.infer<typeof PartSchema>;
export type Feature = Part["features"][number];
export type FeatureType = Feature["type"];
```

```ts
// src/model/expression.ts
export class ExpressionError extends Error {
  constructor(message: string, public readonly expression: string) {
    super(message);
    this.name = "ExpressionError";
  }
}

type Token =
  | { kind: "num"; value: number }
  | { kind: "id"; value: string }
  | { kind: "op"; value: string }
  | { kind: "end" };

const FUNCTIONS: Record<string, (...args: number[]) => number> = {
  sqrt: Math.sqrt,
  abs: Math.abs,
  sin: (x) => Math.sin((x * Math.PI) / 180),
  cos: (x) => Math.cos((x * Math.PI) / 180),
  tan: (x) => Math.tan((x * Math.PI) / 180),
  min: Math.min,
  max: Math.max,
  floor: Math.floor,
  ceil: Math.ceil,
  round: Math.round,
};

function tokenize(src: string): Token[] {
  const tokens: Token[] = [];
  let i = 0;
  while (i < src.length) {
    const c = src[i];
    if (/\s/.test(c)) {
      i++;
    } else if (/[0-9.]/.test(c)) {
      const m = /^[0-9]*\.?[0-9]+(e[+-]?[0-9]+)?|^[0-9]+\.?/i.exec(src.slice(i))!;
      tokens.push({ kind: "num", value: Number(m[0]) });
      i += m[0].length;
    } else if (/[A-Za-z_]/.test(c)) {
      const m = /^[A-Za-z_][A-Za-z0-9_]*/.exec(src.slice(i))!;
      tokens.push({ kind: "id", value: m[0] });
      i += m[0].length;
    } else if ("+-*/^(),".includes(c)) {
      tokens.push({ kind: "op", value: c });
      i++;
    } else {
      throw new ExpressionError(`잘못된 문자 "${c}"`, src);
    }
  }
  tokens.push({ kind: "end" });
  return tokens;
}

class Parser {
  private pos = 0;
  constructor(
    private readonly tokens: Token[],
    private readonly vars: Record<string, number>,
    private readonly src: string,
  ) {}

  private peek(): Token {
    return this.tokens[this.pos];
  }
  private next(): Token {
    return this.tokens[this.pos++];
  }
  private isOp(v: string): boolean {
    const t = this.peek();
    return t.kind === "op" && t.value === v;
  }
  private fail(msg: string): never {
    throw new ExpressionError(msg, this.src);
  }

  parse(): number {
    const value = this.additive();
    if (this.peek().kind !== "end") this.fail("수식 끝에 예상치 못한 토큰");
    return value;
  }

  private additive(): number {
    let left = this.multiplicative();
    while (this.isOp("+") || this.isOp("-")) {
      const op = (this.next() as { value: string }).value;
      const right = this.multiplicative();
      left = op === "+" ? left + right : left - right;
    }
    return left;
  }

  private multiplicative(): number {
    let left = this.power();
    while (this.isOp("*") || this.isOp("/")) {
      const op = (this.next() as { value: string }).value;
      const right = this.power();
      if (op === "/") {
        if (right === 0) this.fail("0으로 나눌 수 없습니다");
        left = left / right;
      } else {
        left = left * right;
      }
    }
    return left;
  }

  private power(): number {
    const base = this.unary();
    if (this.isOp("^")) {
      this.next();
      return Math.pow(base, this.power());
    }
    return base;
  }

  private unary(): number {
    if (this.isOp("-")) {
      this.next();
      return -this.unary();
    }
    if (this.isOp("+")) {
      this.next();
      return this.unary();
    }
    return this.primary();
  }

  private primary(): number {
    const t = this.next();
    if (t.kind === "num") return t.value;
    if (t.kind === "op" && t.value === "(") {
      const v = this.additive();
      if (!this.isOp(")")) this.fail("닫는 괄호가 없습니다");
      this.next();
      return v;
    }
    if (t.kind === "id") {
      if (this.isOp("(")) {
        this.next();
        const fn = FUNCTIONS[t.value];
        if (!fn) this.fail(`알 수 없는 함수 "${t.value}"`);
        const args: number[] = [];
        if (!this.isOp(")")) {
          args.push(this.additive());
          while (this.isOp(",")) {
            this.next();
            args.push(this.additive());
          }
        }
        if (!this.isOp(")")) this.fail("닫는 괄호가 없습니다");
        this.next();
        return fn(...args);
      }
      if (!(t.value in this.vars)) this.fail(`알 수 없는 변수 "${t.value}"`);
      return this.vars[t.value];
    }
    this.fail("값이 필요한 자리에 값이 없습니다");
  }
}

/** 수식 문자열을 숫자로 평가한다. 실패 시 ExpressionError. */
export function evaluate(expression: string, vars: Record<string, number>): number {
  if (expression.trim() === "") throw new ExpressionError("빈 수식", expression);
  const value = new Parser(tokenize(expression), vars, expression).parse();
  if (!Number.isFinite(value)) throw new ExpressionError("결과가 유한한 숫자가 아닙니다", expression);
  return value;
}
```

```ts
// src/model/resolve.ts
import type { Part, Feature } from "./schema";
import { evaluate, ExpressionError } from "./expression";

/** 수식이 아니라 그대로 두어야 하는 문자열 필드 */
const ENUM_KEYS = new Set(["id", "name", "type", "op", "edges", "plane", "kind", "pattern", "direction", "units"]);

export interface FeatureError {
  featureId: string;
  /** 어느 단계에서 실패했는지 */
  stage: "expression" | "kernel";
  message: string;
}

/** 모든 수식이 숫자로 바뀐 피처. 타입 수준에서는 Feature와 같은 모양이지만 string 숫자 필드가 없다. */
export type ResolvedFeature = Feature;

export interface ResolvedPart {
  parameters: Record<string, number>;
  features: ResolvedFeature[];
}

function resolveValue(value: unknown, key: string, vars: Record<string, number>): unknown {
  if (typeof value === "string") {
    if (ENUM_KEYS.has(key)) return value;
    if (key === "depth" && value === "through") return value;
    return evaluate(value, vars);
  }
  if (Array.isArray(value)) return value.map((v, i) => resolveValue(v, String(i), vars));
  if (value && typeof value === "object") {
    const out: Record<string, unknown> = {};
    for (const [k, v] of Object.entries(value)) out[k] = resolveValue(v, k, vars);
    return out;
  }
  return value;
}

export function resolvePart(part: Part): { resolved: ResolvedPart; errors: FeatureError[] } {
  const errors: FeatureError[] = [];
  const features: ResolvedFeature[] = [];
  for (const feature of part.features) {
    if (feature.suppressed) continue;
    try {
      features.push(resolveValue(feature, "", part.parameters) as ResolvedFeature);
    } catch (e) {
      const message = e instanceof ExpressionError ? `${e.message} (수식: "${e.expression}")` : String(e);
      errors.push({ featureId: feature.id, stage: "expression", message });
    }
  }
  return { resolved: { parameters: part.parameters, features }, errors };
}
```

```ts
// src/kernel/evaluate.ts
import { makeBaseBox, makeCylinder, makeSphere, type Shape3D } from "replicad";
import type { ResolvedPart, ResolvedFeature, FeatureError } from "../model/resolve";

export interface EvaluateResult {
  /** 최종 바디. 바디를 만드는 피처가 하나도 없으면 null. */
  shape: Shape3D | null;
  errors: FeatureError[];
}

type Vec3 = [number, number, number];

function applyTransform(shape: Shape3D, transform: ResolvedFeature["transform"]): Shape3D {
  if (!transform) return shape;
  let out = shape;
  const [rx, ry, rz] = (transform.rotation ?? [0, 0, 0]) as Vec3;
  if (rx) out = out.rotate(rx, [0, 0, 0], [1, 0, 0]);
  if (ry) out = out.rotate(ry, [0, 0, 0], [0, 1, 0]);
  if (rz) out = out.rotate(rz, [0, 0, 0], [0, 0, 1]);
  if (transform.position) out = out.translate(transform.position as Vec3);
  return out;
}

/** 바디를 만드는 피처 하나를 독립된 솔리드로 만든다. */
function makeBody(feature: ResolvedFeature): Shape3D | null {
  switch (feature.type) {
    case "box": {
      const [x, y, z] = feature.size as Vec3;
      return makeBaseBox(x, y, z);
    }
    case "cylinder":
      return makeCylinder(feature.radius as number, feature.height as number);
    case "sphere":
      return makeSphere(feature.radius as number);
    default:
      return null;
  }
}

function combine(current: Shape3D | null, body: Shape3D, op: "add" | "cut" | "intersect", featureId: string): Shape3D {
  if (current === null) {
    if (op === "add") return body;
    throw new Error(`"${op}" 연산을 적용할 바디가 아직 없습니다 (피처 "${featureId}" 앞에 바디가 필요합니다)`);
  }
  switch (op) {
    case "add":
      return current.fuse(body);
    case "cut":
      return current.cut(body);
    case "intersect":
      return current.intersect(body);
  }
}

/** 커널 예외는 WebAssembly.Exception일 수 있어 Error로 가정하지 않는다. */
function errorMessage(e: unknown): string {
  if (e instanceof Error) return e.message;
  return `커널 연산 실패: ${String(e)}`;
}

/** 피처를 순서대로 평가해 하나의 바디를 만든다. 실패한 피처는 건너뛰고 오류를 모은다. */
export function evaluateFeatures(part: ResolvedPart): EvaluateResult {
  let current: Shape3D | null = null;
  const errors: FeatureError[] = [];

  for (const feature of part.features) {
    try {
      const body = makeBody(feature);
      if (body === null) continue; // 바디가 아닌 피처는 다음 태스크에서 처리
      const op = "op" in feature ? feature.op : "add";
      current = combine(current, applyTransform(body, feature.transform), op, feature.id);
    } catch (e) {
      errors.push({ featureId: feature.id, stage: "kernel", message: errorMessage(e) });
    }
  }

  return { shape: current, errors };
}
```

```ts
function post(message: WorkerResponse, transfer: Transferable[] = []) {
  self.postMessage(message, transfer);
}

self.onmessage = async (event: MessageEvent<WorkerRequest>) => {
  const request = event.data;
  try {
    await ready;
    const { shape, errors } = evaluateFeatures(request.part);
    if (request.kind === "evaluate") {
      const mesh = shape ? shapeToMesh(shape) : null;
      const transfer = mesh
        ? [mesh.positions.buffer, mesh.normals.buffer, mesh.indices.buffer, mesh.edges.buffer]
        : [];
      post({ kind: "evaluated", requestId: request.requestId, mesh, errors }, transfer);
    } else {
      const data = shape ? await shapeToSTL(shape) : null;
      post({ kind: "stl", requestId: request.requestId, data, errors }, data ? [data] : []);
    }
  } catch (e) {
    post({ kind: "failed", requestId: request.requestId, message: String(e) });
  }
};
```

```ts
/**

export class KernelClient {
  private worker!: Worker;
  private nextId = 1;
  private pending = new Map<number, Pending>();
  private readyPromise!: Promise<void>;

  constructor() {
    this.spawn();
  }

  private spawn() {
    this.worker = new Worker(new URL("./worker.ts", import.meta.url), { type: "module" });
    this.readyPromise = new Promise((resolve) => {
      const onReady = (e: MessageEvent<WorkerResponse>) => {
        if (e.data.kind === "ready") {
          this.worker.removeEventListener("message", onReady);
          resolve();
        }
      };
      this.worker.addEventListener("message", onReady);
    });
    this.worker.onmessage = (e: MessageEvent<WorkerResponse>) => {
      if (e.data.kind === "ready") return;
      const p = this.pending.get(e.data.requestId);
      if (!p) return;
      this.pending.delete(e.data.requestId);
      p.resolve(e.data);
    };
    this.worker.onerror = (e) => {
      const error = new Error(`커널 워커 오류: ${e.message}. 워커를 다시 시작합니다.`);
      for (const p of this.pending.values()) p.reject(error);
      this.pending.clear();
      this.worker.terminate();
      this.spawn();
    };
  }

  ready(): Promise<void> {
    return this.readyPromise;
  }

  private send(request: WorkerRequest): Promise<WorkerResponse> {
    return new Promise((resolve, reject) => {
      this.pending.set(request.requestId, { resolve, reject });
      this.worker.postMessage(request);
    });
  }

  async evaluate(part: ResolvedPart): Promise<{ mesh: MeshData | null; errors: FeatureError[] }> {
    const res = await this.send({ kind: "evaluate", requestId: this.nextId++, part });
    if (res.kind === "failed") throw new Error(res.message);
    if (res.kind !== "evaluated") throw new Error("예상치 못한 워커 응답");
    return { mesh: res.mesh, errors: res.errors };
  }

  async exportSTL(part: ResolvedPart): Promise<{ data: ArrayBuffer | null; errors: FeatureError[] }> {
    const res = await this.send({ kind: "exportSTL", requestId: this.nextId++, part });
    if (res.kind === "failed") throw new Error(res.message);
    if (res.kind !== "stl") throw new Error("예상치 못한 워커 응답");
    return { data: res.data, errors: res.errors };
  }
}
```

```ts
// src/state/store.ts
import { create } from "zustand";
import { PartSchema, type Part } from "../model/schema";
import { resolvePart, type FeatureError } from "../model/resolve";
import { KernelClient } from "../kernel/client";
import type { MeshData } from "../kernel/protocol";

export interface SchemaError {
  path: string;
  message: string;
}

interface State {
  part: Part | null;
  mesh: MeshData | null;
  featureErrors: FeatureError[];
  schemaErrors: SchemaError[];
  kernelStatus: "loading" | "ready" | "busy";
  /** 파일 내용(JSON 문자열)을 받아 검증·평가한다. */
  loadJson: (text: string) => void;
  exportSTL: () => Promise<ArrayBuffer | null>;
}

const kernel = new KernelClient();
let evaluationSeq = 0;

export const useStore = create<State>((set, get) => {
  kernel.ready().then(() => set({ kernelStatus: "ready" }));

  async function evaluate(part: Part) {
    const seq = ++evaluationSeq;
    const { resolved, errors: exprErrors } = resolvePart(part);
    set({ kernelStatus: "busy" });
    try {
      const { mesh, errors: kernelErrors } = await kernel.evaluate(resolved);
      if (seq !== evaluationSeq) return; // 더 새로운 평가가 있으면 버린다
      set({ mesh, featureErrors: [...exprErrors, ...kernelErrors], kernelStatus: "ready" });
    } catch (e) {
      if (seq !== evaluationSeq) return;
      set({
        featureErrors: [...exprErrors, { featureId: "*", stage: "kernel", message: String(e) }],
        kernelStatus: "ready",
      });
    }
  }

  return {
    part: null,
    mesh: null,
    featureErrors: [],
    schemaErrors: [],
    kernelStatus: "loading",

    loadJson(text) {
      let raw: unknown;
      try {
        raw = JSON.parse(text);
      } catch (e) {
        set({ schemaErrors: [{ path: "", message: `JSON 문법 오류: ${String(e)}` }] });
        return;
      }
      const result = PartSchema.safeParse(raw);
      if (!result.success) {
        set({
          schemaErrors: result.error.issues.map((i) => ({ path: i.path.join("."), message: i.message })),
        });
        return; // 마지막 성공 모델(part, mesh)은 유지한다
      }
      set({ part: result.data, schemaErrors: [] });
      void evaluate(result.data);
    },

    async exportSTL() {
      const part = get().part;
      if (!part) return null;
      const { resolved } = resolvePart(part);
      const { data } = await kernel.exportSTL(resolved);
      return data;
    },
  };
});
```

```ts
type PatternSpec = NonNullable<Extract<ResolvedFeature, { type: "box" }>["pattern"]>;

/** 패턴 사양을 XY 오프셋 목록으로 푼다. 패턴이 없으면 원점 하나. */
export function patternOffsets(pattern: PatternSpec | undefined): [number, number, number][] {
  if (!pattern) return [[0, 0, 0]];
  const count = Math.max(1, Math.round(pattern.count as number));
  if (pattern.pattern === "linear") {
    const spacing = pattern.spacing as number;
    const axis = { X: [1, 0, 0], Y: [0, 1, 0], Z: [0, 0, 1] }[pattern.direction] as [number, number, number];
    return Array.from({ length: count }, (_, i) => [axis[0] * spacing * i, axis[1] * spacing * i, axis[2] * spacing * i]);
  }
  const r = (pattern.diameter as number) / 2;
  const start = ((pattern.startAngle as number) * Math.PI) / 180;
  return Array.from({ length: count }, (_, i) => {
    const a = start + (2 * Math.PI * i) / count;
    return [r * Math.cos(a), r * Math.sin(a), 0];
  });
}

/** 바디 하나를 패턴대로 복제해 하나로 합친다. */
function applyPattern(body: Shape3D, pattern: PatternSpec | undefined): Shape3D {
  const offsets = patternOffsets(pattern);
  let out: Shape3D | null = null;
  for (const offset of offsets) {
    const instance = body.clone().translate(offset);
    out = out ? out.fuse(instance) : instance;
  }
  return out!;
}
```

```ts
// server/projectFile.ts
import { readFileSync, writeFileSync } from "node:fs";

/** 프로젝트 파일 하나의 읽기/쓰기. 자기가 쓴 내용은 기억해 감시 이벤트에서 되돌아오는 변경을 걸러낸다. */
export class ProjectFile {
  private lastWritten: string | null = null;

  constructor(public readonly path: string) {}

  get errorsPath(): string {
    return this.path.replace(/\.json$/, ".errors.json");
  }

  read(): string {
    return readFileSync(this.path, "utf8");
  }

  /** 내용이 실제로 바뀌었을 때만 쓰고 true를 돌려준다. */
  write(value: unknown): boolean {
    const text = JSON.stringify(value, null, 2) + "\n";
    const current = this.safeRead();
    if (current === text) return false;
    writeFileSync(this.path, text);
    this.lastWritten = text;
    return true;
  }

  writeErrors(errors: unknown): void {
    writeFileSync(this.errorsPath, JSON.stringify(errors, null, 2) + "\n");
  }

  isOwnContent(text: string): boolean {
    return this.lastWritten === text;
  }

  private safeRead(): string | null {
    try {
      return this.read();
    } catch {
      return null;
    }
  }
}
```

```ts
import type { ClientMessage, ServerMessage } from "../../server/protocol";

const URL = `ws://${location.hostname}:5174`;

/** 서버와의 WebSocket 연결. 끊기면 2초마다 재접속한다. */
export class Connection {
  private socket: WebSocket | null = null;
  private status: "connecting" | "open" | "closed" = "connecting";

  constructor(
    private readonly onMessage: (m: ServerMessage) => void,
    private readonly onStatus: (s: "connecting" | "open" | "closed") => void,
  ) {
    this.connect();
  }

  private connect() {
    this.setStatus("connecting");
    const socket = new WebSocket(URL);
    this.socket = socket;
    socket.onopen = () => this.setStatus("open");
    socket.onmessage = (e) => this.onMessage(JSON.parse(e.data) as ServerMessage);
    socket.onclose = () => {
      this.setStatus("closed");
      setTimeout(() => this.connect(), 2000);
    };
    socket.onerror = () => socket.close();
  }

  private setStatus(s: typeof this.status) {
    this.status = s;
    this.onStatus(s);
  }

  send(message: ClientMessage) {
    if (this.socket?.readyState === WebSocket.OPEN) this.socket.send(JSON.stringify(message));
  }
}
```

```ts
// src/model/edit.ts
import type { Part, Feature } from "./schema";

export function setParameter(part: Part, name: string, value: number): Part {
  return { ...part, parameters: { ...part.parameters, [name]: value } };
}

export function updateFeature(part: Part, id: string, patch: Partial<Feature>): Part {
  return {
    ...part,
    features: part.features.map((f) => (f.id === id ? ({ ...f, ...patch } as Feature) : f)),
  };
}

export function moveFeature(part: Part, id: string, toIndex: number): Part {
  const features = [...part.features];
  const from = features.findIndex((f) => f.id === id);
  if (from < 0) return part;
  const [item] = features.splice(from, 1);
  features.splice(toIndex, 0, item);
  return { ...part, features };
}

export function deleteFeature(part: Part, id: string): Part {
  return { ...part, features: part.features.filter((f) => f.id !== id) };
}

export function toggleSuppressed(part: Part, id: string): Part {
  return {
    ...part,
    features: part.features.map((f) => (f.id === id ? { ...f, suppressed: !f.suppressed } : f)),
  };
}
```

```tsx
// src/ui/NumField.tsx
import { useEffect, useState } from "react";
import type { Num } from "../model/schema";

/**
 * 숫자 또는 수식 문자열을 편집한다. 입력 중에는 로컬 상태를 쓰고,
 * blur 또는 Enter에서 커밋한다. 숫자로 파싱되면 number, 아니면 수식 문자열로 저장.
 */
export function NumField({ label, value, onCommit }: { label: string; value: Num; onCommit: (v: Num) => void }) {
  const [text, setText] = useState(String(value));
  useEffect(() => setText(String(value)), [value]);

  function commit() {
    const trimmed = text.trim();
    if (trimmed === "" || trimmed === String(value)) return;
    const n = Number(trimmed);
    onCommit(Number.isFinite(n) ? n : trimmed);
  }

  return (
    <label style={{ display: "flex", alignItems: "center", gap: 8, padding: "3px 0" }}>
      <span style={{ width: 90, color: "#555" }}>{label}</span>
      <input
        value={text}
        onChange={(e) => setText(e.target.value)}
        onBlur={commit}
        onKeyDown={(e) => e.key === "Enter" && (e.target as HTMLInputElement).blur()}
        style={{ flex: 1, fontFamily: "monospace", fontSize: 13, padding: "2px 6px" }}
      />
    </label>
  );
}
```

```tsx
import { NumField } from "./NumField";
import type { Feature, Num } from "../model/schema";

/** 필드 이름의 한국어 라벨 */
const LABEL: Record<string, string> = {
  radius: "반경", height: "높이", size: "크기", diameter: "지름", depth: "깊이", distance: "거리",
  width: "폭", offset: "오프셋", cornerRadius: "코너 반경", sides: "변 수", count: "개수",
  spacing: "간격", startAngle: "시작 각도", position: "위치", rotation: "회전",
};

const SKIP = new Set(["id", "type", "name", "suppressed", "op", "edges", "plane", "kind", "pattern", "direction", "positions"]);

type Path = (string | number)[];

function setAt(obj: unknown, path: Path, value: unknown): unknown {
  if (path.length === 0) return value;
  const [head, ...rest] = path;
  if (Array.isArray(obj)) {
    const copy = [...obj];
    copy[head as number] = setAt(obj[head as number], rest, value);
    return copy;
  }
  const record = (obj ?? {}) as Record<string, unknown>;
  return { ...record, [head]: setAt(record[head as string], rest, value) };
}

function Fields({ obj, path, onChange }: { obj: Record<string, unknown>; path: Path; onChange: (path: Path, v: Num) => void }) {
  return (
    <>
      {Object.entries(obj).map(([key, value]) => {
        if (SKIP.has(key)) return null;
        const label = LABEL[key] ?? key;
        if (typeof value === "number" || typeof value === "string") {
          if (key === "depth" && value === "through") return null;
          return <NumField key={key} label={label} value={value} onCommit={(v) => onChange([...path, key], v)} />;
        }
        if (Array.isArray(value) && value.every((v) => typeof v === "number" || typeof v === "string")) {
          const axis = ["X", "Y", "Z"];
          return value.map((v, i) => (
            <NumField key={`${key}${i}`} label={`${label} ${axis[i] ?? i}`} value={v as Num} onCommit={(nv) => onChange([...path, key, i], nv)} />
          ));
        }
        if (value && typeof value === "object") {
          return (
            <div key={key} style={{ marginTop: 6 }}>
              <div style={{ color: "#888", fontSize: 12 }}>{label}</div>
              <Fields obj={value as Record<string, unknown>} path={[...path, key]} onChange={onChange} />
            </div>
          );
        }
        return null;
      })}
    </>
  );
}

export function Inspector() {
  const part = useStore((s) => s.part);
  const selectedId = useStore((s) => s.selectedFeatureId);
  const { setParameter, updateFeature } = useStore.getState();
  if (!part) return null;
  const feature = part.features.find((f) => f.id === selectedId);

  return (
    <div style={{ padding: 12, fontSize: 13, borderTop: "1px solid #eee" }}>
      <div style={{ fontWeight: 600, marginBottom: 6 }}>파라미터</div>
      {Object.entries(part.parameters).map(([name, value]) => (
        <NumField key={name} label={name} value={value} onCommit={(v) => typeof v === "number" && setParameter(name, v)} />
      ))}
      {Object.keys(part.parameters).length === 0 && <div style={{ color: "#888" }}>없음</div>}

      {feature && (
        <>
          <div style={{ fontWeight: 600, margin: "14px 0 6px" }}>{feature.name ?? feature.id} <span style={{ color: "#888", fontWeight: 400 }}>({feature.type})</span></div>
          <Fields
            obj={feature as unknown as Record<string, unknown>}
            path={[]}
            onChange={(path, v) => updateFeature(feature.id, setAt(feature, path, v) as Partial<Feature>)}
          />
        </>
      )}
    </div>
  );
}
```

파라미터 입력은 숫자만 받는다(파라미터는 스키마상 `number`). 수식을 넣으면 무시된다.
